# CoreLink Website Agent Context

This repository is part of the CoreLink product.

## Canonical context

Follow `CoreLinkPlatform/product-planning/AGENTS.md`, `PRODUCT_ARCHITECTURE.md`, `GLOSSARY.md`, `STANDARDS.md`, `design/DESIGN.md`, `design/BRAND.md`, `design/tokens.json`, and `architecture/repository-map.yaml`.

## Repository responsibility

`website` owns the public CoreLink product website, positioning, product discovery, public-facing product information, and paths into developer resources.

## Boundaries

- Do not publish private roadmap details, internal architecture, customer secrets, credentials, or operational diagnostics.
- Product claims must reflect supported or clearly marked planned capabilities.
- Use canonical CoreLink terminology, brand assets, typography, colors, and design rules; do not invent replacements.
- Developer technical details should link to `developer-docs` rather than duplicating normative documentation.
- Public API/schema behavior must not be redefined here.
